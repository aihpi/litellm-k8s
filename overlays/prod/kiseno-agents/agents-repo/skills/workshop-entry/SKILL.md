# Workshop entry in EspoCRM

1. Collect title, date, place and format from the request. Ask for whatever is missing, in one question.
2. Search EspoCRM for an existing event with the same title and date before creating one.
3. Create the event, or update the existing one, with the EspoCRM tools.
4. Reply with what you created or changed and the link to the record.
